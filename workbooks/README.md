# Excel workbooks

The project includes **10 STARTER** and **10 SOLUTION** workbooks corresponding to the 10 practice cases described in the [main README](../README.md).

The 20 original files can currently be downloaded for free, without registration, from the **[official project website](https://excel-finance-book.pages.dev/)**.

This directory is reserved for the **original** files. No recreated or placeholder spreadsheets will be published here. When the originals are uploaded, their existing filenames will be retained.
